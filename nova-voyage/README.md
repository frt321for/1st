# 新航 Nova Voyage · 404

虚构太空旅行品牌的交互式 404 页面。月球组成错误码中的 0，访客可以归航地球、返回上一站，或通过地球联络站复制当前位置。

## 预览

在本目录运行：

```powershell
node serve.mjs
```

打开 http://localhost:4173 。也可以直接打开 `index.html`。页面、字体与图片均为本地文件，无构建步骤和运行时依赖。

默认展示 404 场景，`#earth` 展示归航后的地球站，`#lost` 返回未知星域。地址栏前进、后退与刷新均保留目的地。复制功能需要浏览器授予剪贴板访问权限；受限时可选中航行信息手动复制。

## 文件

- `index.html`：页面内容、404 与地球站状态、联络站对话框。
- `styles.css`：视觉样式、响应式布局、交互过渡和减少动态效果支持。
- `app.js`：归航、历史导航、联络站与星图视差。
- `assets/`：本地字体、WebP 行星和素材来源说明。

这是独立的页面作品。`serve.mjs` 为本地预览服务器，首页以 200 响应展示作品；访问缺失路径时以 404 响应返回此页面。部署时可将页面配置为网站的错误文档，并将归航操作接到实际首页。
